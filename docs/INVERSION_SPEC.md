# 3D-инверсия: принятый объём и состояние

Реализована третья вкладка GeoGarModel 2.2. Руководство пользователя,
физическая постановка и ограничения: [INVERSION.md](INVERSION.md).

Подтверждённый ориентир — GravMagInv3D компании Lolgeo. Пользователь предоставил
[страницу руководств](https://gravmaginv.ru/manuals). Получены руководство
GravMagInv3D на 98 страницах и спецификация от 10.01.2024 для версии 2023.12.01+.
Реализация GeoGarModel самостоятельная; совпадение всех деталей закрытого
решателя и численных результатов GravMagInv3D не заявляется.

Приняты три режима: гравитационная инверсия контраста плотности,
индуцированная магнитная инверсия восприимчивости и векторная магнитная
инверсия суммарной намагниченности, допускающая остаточную составляющую.
Поддержаны CPU и NVIDIA CUDA, трёхмерная сетка призм, ограничения свойств,
глубинный индекс, L2/гладкость, точная ΔT и контроль сходимости.

Визуализация: VTK-сцена с вокселями, объёмом, изоповерхностями,
ортогональными срезами и плоскостью отсечения. Экспорт/повторное открытие NPZ,
экспорт VTK и CSV полей. Примеры для трёх режимов встроены в приложение.

Отдельно восстановить индуцированную и остаточную составляющие по одной
скалярной ΔT нельзя: векторный результат — суммарный J.
Совместная структурная инверсия двух полей не включена в текущую реализацию.
Сравнение с исполняемой GravMagInv3D возможно после получения эталонного проекта.

Прежнее ТЗ межслойной инверсии с мягкими ML/DL-горизонтами снято с плана
по решению пользователя из-за отсутствия входных данных. Оно сохранено в истории Git.
