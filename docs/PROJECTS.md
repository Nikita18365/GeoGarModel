# Общий проект GeoGarModel

**Один проект сохраняет работу во всех трёх разделах приложения.**
Файл `.ggproject` содержит сами данные, а не только ссылки на исходные файлы.
Для переноса работы на другой компьютер достаточно скопировать файл проекта.

## Основные команды

1. **Проект → Создать…** (`Ctrl+N`): введите общее название и СК карт.
   При наличии несохранённых изменений программа предложит сохранить текущий
   проект. Новый проект очищает все три раздела, а не только карты.
2. Работайте в разделах карт, прогноза/Optuna и 3D-моделирования.
3. **Проект → Сохранить** (`Ctrl+S`): выберите файл `.ggproject`.
   **Сохранить как…** создаёт отдельный файл-снимок текущей работы.
4. **Проект → Открыть…** (`Ctrl+O`): выберите проект. Восстановятся данные,
   результаты и настройки всех разделов, включая внутренние 3D-окна.
5. **Проект → Закрыть** закрывает общий проект. Исходные файлы не удаляются.

Название общее для всего приложения. СК проекта управляет приведением карт и
контуров в картографическом разделе. В ML и 3D сохраняются их собственные
настройки координат; загрузка проекта не перепроецирует воксели или наблюдения.

## Что сохраняется

| Раздел | Содержимое проекта |
|---|---|
| Карты и трансформанты | Сетки с данными и масками, результаты трансформант и история операций; SHP/GeoJSON как геометрия; порядок, названия и видимость слоёв; палитры и диапазоны, изолинии, теневой рельеф; заголовок, масштабная линейка, географические подписи; параметры компоновки и текущий охват карты. |
| ML и Optuna | Обучающая и прогнозная таблицы, выбранные координаты, признаки и горизонт; метод, ручные параметры, пространство поиска, число trials, CV, CPU/GPU; история завершённых trials и лучший результат; обученная итоговая модель, метрики, контрольные точки и невязки; готовый прогноз, графики и их диапазоны. |
| 3D-моделирование | Таблица наблюдений и сопоставление столбцов; параметры физики, сетки и решателя; начальный воксель и предыдущая версия для отмены операции; результат инверсии, рассчитанное поле и история сходимости; общий каталог моделей и исходные пути. |
| 3D-окна | Состав каждого окна, выбранная модель, расположение и свёрнутое/развёрнутое состояние; ракурс, масштаб осей, палитра и цветовой диапазон, прозрачность, детализация, координаты сечений и область визуального отсечения — отдельно для моделей каждого окна. |

Пути к источникам остаются в каталоге для удобства, но при открытии используются
**встроенные данные проекта**. Поэтому перемещение или отсутствие исходного
NPZ/VTK/UBC-файла не мешает открыть уже сохранённую модель. Пользовательские
цветовые шкалы, используемые картами и 3D-моделями, также сохраняются.

## Обученные модели после открытия

Нажмите **Прогнозировать**: сохранённый конвейер предварительной обработки и
обученная модель используются без повторного обучения. Поддерживаются все
методы, доступные в программе. Для XGBoost, LightGBM, CatBoost и PyTorch на
новом компьютере должна быть установлена соответствующая дополнительная
библиотека. Таблицы, готовые прогнозы, метрики и графики доступны и без неё.

Переносимый прогноз сохранённых моделей выполняется на CPU, чтобы файл проекта
не зависел от наличия конкретного GPU. Выбор CPU/GPU для нового обучения и
инверсии сохраняется в настройках. Геометрия 3D заново готовится при открытии;
для интерактивного просмотра нужен пакет `volume` и рабочий графический драйвер.

Для sklearn используется формат skops с фиксированным списком поддерживаемых
численных типов; для бустингов — их штатные форматы, для нейросетей — численные
массивы весов. Проект не загружает произвольные pickle-объекты. При переносе
между существенно различающимися версиями библиотек может потребоваться
обновить окружение; список версий библиотек записывается в манифест проекта.

## Сохранение во время расчёта

Сохранение создаёт снимок **уже готовых данных**: например, завершённые trials
Optuna на момент сохранения и ранее полученные 3D-результаты.
Незавершённый trial, внутренняя память решателя, GPU-кэш и выполняющийся поток
в проект не входят. Открытие файла не продолжает остановленную вычислительную
итерацию. После завершения расчёта сохраните проект ещё раз, чтобы включить
итоговую модель. Для смены проекта во время расчёта сначала дождитесь завершения
или остановите расчёт штатной кнопкой.

## Старые проекты карт

Файлы `.ggmaps` открываются через то же меню. Если файл старого формата содержит
только карты, восстанавливается картографический раздел; остальные разделы
начинают пустыми. Затем используйте **Сохранить как…** и расширение `.ggproject`,
чтобы сохранить общий проект. Чтение карт из нового общего файла также
поддерживается картографическим загрузчиком GeoGarModel.

Сохранение выполняется через временный файл и атомарную замену: ошибка записи
не заменяет ранее сохранённый проект частично записанным файлом. Размер проекта
зависит от числа сеток, таблиц и моделей; большие воксели увеличивают время
сохранения и открытия.
