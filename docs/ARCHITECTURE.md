# Структура GeoGarModel

```text
geogarmodel/
  app.py            PyQt5: загрузка, формы, фоновые задания, экспорт
  theme.py          палитра, стили, оформление Matplotlib
  dashboard.py      PyQtGraph: Optuna, параметры, диагностика, карты контроля
  models.py         схема данных, внешнее разбиение, обучение, итоговая модель
  optimization.py   TPE, пространства поиска, внутренняя CV, pruning, история
  compute.py        CPU/GPU-политика, проверка устройства, отмена
  neural.py         PyTorch residual MLP / feature-token Transformer
  grids.py          регулярная сетка, ZMAP/NPZ/XYZ, обрезка
  fields.py         физические трансформанты и региональное/локальное поле
  coordinates.py    CRS и зоны ГСК-2011
  plotting.py       отображение регулярных карт и векторных наложений
  demo.py           воспроизводимый синтетический пример
tests/              вычисления, Optuna, Qt, графики, optional-модели
docs/               инструкции и постановки следующих модулей
```

Численные модули не зависят от Qt. `train_horizon` получает обычную таблицу,
настройки, callback прогресса и событие отмены. Worker передаёт callback в Qt-сигнал;
`dashboard.py` изменяет графики только в главном потоке. `TrainingResult` объединяет
конвейер, контрольные данные, параметры разбиения, метрики и историю оптимизации.

Разделение train/holdout принадлежит `models.py`; `optimization.py` видит только
обучающую часть и её внутренние фолды. Это граница, которая предотвращает утечку
внешних контрольных глубин в оптимизацию. Все модели используют одну схему
признаков и одинаковые конвейеры подготовки.

Коммиты группируются по ответственности: ядро Optuna/устройства, движки графиков,
интеграция интерфейса, проверки/исправления и документация. Не смешивайте изменение
физического оператора с косметическим переоформлением форм.

Проверка: `python -m pytest -q`. Optional-модели пропускаются, если пакет не
установлен. CI устанавливает их в отдельном Windows-задании; основная матрица —
Windows/Linux и Python 3.11/3.13. GPU-smoke можно включить отдельно переменной
`GEOGARMODEL_GPU_TESTS=1` на машине с XGBoost и NVIDIA CUDA; обычный CI не имеет GPU.
Тесты Qt используют offscreen. Показанные на графиках данные могут быть сокращены
для скорости; численные тесты и экспорт используют полные массивы.
