# Проекты карт и трансформанты

## Проект магнитных или гравиметрических карт

1. Откройте **Проект карт → Создать…**, введите своё название, например
   «Магнитное поле — Анабар», и выберите СК проекта, например
   `EPSG:20918 | GSK-2011 / Gauss-Kruger zone 18`. Для существующего проекта
   используйте **Проект карт → Система координат…** или кнопку **СК проекта…**.
2. На шаге **1 · Карта** загрузите сетки ZMAP/DAT/NPZ или таблицу XYZ.
3. Для каждой карты проверьте **CRS и единицы карты…**: единицы поля (nT, mGal
   и другие), координат и систему координат. При заданной СК проекта изменение
   исходной СК карты вызывает её перепроецирование в СК проекта. Единицы поля
   автоматически не пересчитываются. Для трансформант требуются метрические координаты.
4. Выберите **Проект карт → Сохранить**. Файл `.ggmaps` содержит сами сетки,
   векторные контуры, названия, порядок, видимость, оформление и текущий масштаб.
   Для повторного открытия исходные файлы не нужны.
5. Выберите **Проект карт → Закрыть**, затем создайте другой проект, например
   «Аномалии гравитационного поля в редукции Буге». При несохранённых изменениях
   программа предложит сохранить их, отбросить или отменить закрытие.
6. Для возвращения выберите **Проект карт → Открыть…** и нужный `.ggmaps`.

Проект карт относится только к первому модулю. Таблицы обучения и результаты
3D-моделирования в него не входят. Переключение проектов во время фонового расчёта
заблокировано, чтобы результат трансформанты не попал в другой проект.

## Слои: что показывать и в каком порядке

- Галочка слева включает отображение карты или векторного контура. Можно
  одновременно включить несколько слоёв. Выделение строки выбирает слой для
  оформления, экспорта или расчёта; это отдельное действие от галочки видимости.
- Верхняя строка списка отображается впереди нижних. Перетаскивайте строки мышью,
  чтобы изменить порядок, либо используйте правую кнопку → **Выше / Ниже**.
  Перемещение сохраняет данные, оформление и галочку слоя.
  Непрозрачная верхняя карта перекроет нижнюю там, где
  у неё есть значения; пропуски прозрачны. Для смешивания задайте
  **3 · Вид → Непрозрачность слоя**, например `0,5`.
- Переименуйте слой двойным щелчком, клавишей F2 или через правую кнопку мыши →
  **Переименовать**. Для удаления выделите строку и нажмите Delete, пока фокус
  находится в списке, либо выберите правой кнопкой мыши → **Удалить**.
  Исходный файл на диске при этом не удаляется.
- Оформление хранится отдельно для каждой карты. Выберите карту в списке,
  перейдите на **3 · Вид** и измените нужный параметр. Изолинии и отмывка не
  сбрасываются при смене палитры, диапазона или названия; текущий масштаб
  сохраняется. Вернуть общий охват можно командой
  **Проект карт → Вписать все видимые карты**.

## Общая система координат проекта

Выберите метрическую СК проекта при создании либо кнопкой **СК проекта…**.
Все вновь импортируемые карты и векторы автоматически преобразуются в неё.
Смена СК существующего проекта перепроецирует все его слои, включая скрытые.
Если преобразование какого-либо слоя не удалось или пользователь отменил ввод
исходной СК, замена данных проекта не выполняется.

Для таблиц и сеток без информации о СК программа запрашивает **исходную СК**.
Указывайте систему реальных координат файла, а не желаемую СК проекта. Например,
для долготы/широты WGS84 это EPSG:4326. Без исходной СК достоверное преобразование
невозможно. Согласуйте также зональный префикс East с параметрами проекции.

Растры пересчитываются линейной интерполяцией на регулярную сетку в СК проекта.
Количество узлов по каждой оси сохраняется (не менее трёх при перепроецировании).
Вне преобразованной области остаются пропуски; значения не экстраполируются.
Интерполяция может сгладить пики и расширить пропуски рядом с NaN. Это изменение
данных сетки, а не только подписей осей; поле не пересчитывается на новую высоту.
При той же исходной и целевой СК свойства копируются без интерполяции.

Координаты SHP/GeoJSON преобразуются напрямую без растрирования. Файлы-источники
на диске не изменяются; `.ggmaps` сохраняет преобразованные данные и СК проекта.
При многократных сменах СК растр интерполируется повторно; для сохранения качества
выбирайте рабочую СК заранее и храните исходные файлы отдельно.

Цветовая шкала справа относится к верхней видимой карте; у нижних карт сохраняется
собственная нормировка. Старые `.ggmaps` открываются: общую СК можно назначить
через **СК проекта…**. В рабочем пространстве без явной настройки используется СК
первой карты, если она известна.

## Как рассчитать трансформанту

Выделите исходную карту, откройте **2 · Расчёт**, выберите метод. Показываются
только параметры, которые относятся к выбранной операции.

| Трансформанта | Что задавать |
| --- | --- |
| Производные X/Y, первая и вторая вертикальные производные | Дополнительных параметров нет: нажмите «Рассчитать → новый слой». |
| Горизонтальный градиент, аналитический сигнал, Tilt | Дополнительных параметров нет. |
| Продолжение вверх, локальное поле после продолжения | Высота продолжения в метрах. |
| Полиномиальный тренд, локальное поле после вычитания тренда | Степень тренда 1–3. |
| Гауссов низко-/высокочастотный фильтр | Длина волны фильтра в метрах. |

Результат появляется новым верхним слоем. Исходная карта остаётся в проекте.
Для FFT используется прежнее дополнение краёв на 25%; отдельный ввод не требуется.
Методика расчёта и влияние краёв описаны в [основном руководстве](MODERNIZATION.md).

## Изолинии и оформление

Выделите нужную карту → **3 · Вид** → включите **Изолинии**. Появятся:

- **Сечение изолиний** — шаг в единицах поля, например `10` для карты в nT
  означает уровни … −20, −10, 0, 10, 20 … nT. `Авто` выбирает уровни автоматически.
- **Цвет изолиний** — нажмите «Выбрать цвет…» и выберите оттенок в палитре.
  Образец текущего цвета показан прямо на кнопке.
- **Толщина изолиний** — ширина линий; отдельная галочка включает подписи значений.

Если шаг даёт больше 1000 уровней, увеличьте его. При крупном шаге и отсутствии
уровней внутри диапазона карты линии не рисуются. Для больших сеток построение
изолиний использует прореживание до приблизительно 512 узлов по каждой оси.

Палитра, нормировка, диапазон, заголовок, отмывка и непрозрачность применяются
к выбранной карте. Изменения переключателей и числовых полей отображаются сразу;
текстовое поле применяется после завершения редактирования (Enter или выход из
поля). Кнопка «Применить оформление» также доступна.

## SHP и GeoJSON

Задайте СК проекта → **1 · Карта → Контуры и обрезка → Добавить
SHP / GeoJSON**. Контур появится отдельной строкой с галочкой, которую можно
перемещать, переименовывать и удалять. Векторные координаты преобразуются в СК
проекта при загрузке. Поддерживаются точки, линии, полигоны и составные
геометрии; полигоны показываются контурами без заливки.

Для SHP держите рядом связанные `.shx`, `.dbf`, `.prj`; если `.prj` отсутствует,
программа запросит исходную СК вручную. GeoJSON без явной CRS считается WGS84
(`EPSG:4326`, долгота/широта). Атрибуты SHP/GeoJSON в таблицу проекта не импортируются.

GeoJSON читается встроенными средствами, SHP — лёгкой библиотекой pyshp,
входящей в основную установку. Если проект обновлён через git, обновите зависимости:

```powershell
.\.venv\Scripts\python -m pip install -e .
```

## Оси и масштабная линейка

Подписи метрических осей — **X, м** и **Y, м**. Для старых карт с неизвестными
единицами отображаются такие же подписи по принятому в приложении метрическому
соглашению; это не конвертация координат. Проверьте единицы в метаданных. Карты
с явно заданными градусами подписываются в градусах, FFT и линейка в метрах для
них недоступны.

На шаге **3 · Вид** включите **Масштабная линейка**. Выберите **м** или **км**,
укажите шаг в выбранных единицах и число делений (1–20). `Авто` подбирает шаг
по текущей ширине видимой области. Например, шаг `1 км` и четыре деления дают
линейку от 0 до 4 км. Смена единиц сохраняет физическую длину: 1000 м = 1 км.
Галочка **Подписывать СК под линейкой** выводит имя и EPSG фактической СК проекта.
Линейка следует за горизонтальным перемещением/масштабированием карты. Если
заданная длина больше видимого охвата, уменьшите шаг или число делений.

Линейка находится **под графиком**, вне области карты. Её начало выровнено по
первой видимой основной риске оси X. Числа линейки показывают расстояния от её
начала, а не абсолютные координаты East. Вертикальное положение рассчитывается
от нижней границы подписи X с небольшим отступом, чтобы элементы не пересекались.

Заголовок блока оформления содержит имя выделенной карты. Длинное имя переносится
на следующую строку. При переименовании в списке редактор имеет увеличенную
высоту, чтобы текст оставался видимым.

Кнопка **«Домой» (домик)** возвращает полный охват всех видимых карт, включая
после оформления увеличенного участка. Колесо мыши над картой приближает и
отдаляет её вокруг позиции курсора. Обычное изменение оформления сохраняет
выбранную область просмотра.

На шаге **3 · Вид → Символ севера** доступны стрелка **N**, стрелка **С**,
компасная стрелка или скрытие символа. Выбранный символ находится над цветовой
шкалой и указывает географический север в центре
текущей области карты, рассчитанный по её CRS. В проекции Гаусса—Крюгера её
наклон может отличаться от вертикали из-за сближения меридианов. Это не магнитный
север. Если CRS не задана, показывается «N сетки» вдоль положительной оси Y;
если CRS не согласуется с координатами и направление вычислить нельзя — «N ?».
Проверьте EPSG/параметры проекции и наличие зонального префикса в координате East.
